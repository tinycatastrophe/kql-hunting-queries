# kql-hunting-queries
A collection of KQL threat hunting queries for security monitoring, investigation, and threat detection across Microsoft security platforms. Queries are organized by hunting use case and include relevant context where applicable.


Structure
queries/
├── authentication/
├── endpoint/
├── network/
├── persistence/
└── discovery/


Usage

Queries are intended for use with Microsoft security platforms such as Microsoft Defender XDR, Microsoft Sentinel, and related KQL-based services.

Each query includes relevant context such as its purpose, data source, and MITRE ATT&CK mapping where applicable.

Disclaimer

These queries are provided for research, learning, and defensive security purposes. Queries may require modification depending on your environment, available data sources, and schema.
